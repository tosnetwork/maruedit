# Naming and Trademark Search Record

Search date: 2026-08-05. Proposed product/repository name: **MaruEdit**.

The release audit searched the exact term and close software-editor matches in
general web results, GitHub repositories, Apple App Store results, the USPTO
search surface, and Japan Platform for Patent Information search results. The
exact GitHub repository search returned only `tosnetwork/maruedit`; indexed web
results did not identify another text editor using the exact MaruEdit name.
Nearby established software names include MarcEdit, MarsEdit, and MarkEdit, so
the project must consistently use the complete MaruEdit word/logo and avoid
visual or marketing claims that could create confusion.

This is a documented release search, not a legal opinion or guarantee that no
unindexed, pending, regional, or common-law rights exist. Before commercial
distribution, paid promotion, or trademark registration, the publisher should
obtain a professional clearance search in the intended jurisdictions.

The product statement must remain prominent: MaruEdit is an independent
open-source project and is not affiliated with or endorsed by the developers
of OldMaru Editor. The OldMaru name is used only to describe compatibility
and migration context.
